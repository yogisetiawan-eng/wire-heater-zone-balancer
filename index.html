How it calculates

Test power per side comes from the wiring. In one series string every side carries the same current, so Pᵢ = I²·Ω/mᵢ·Lᵢ with I = V / ΣRᵢ. With a separate string per side, Pᵢ = V² / (Ω/mᵢ·Lᵢ). Each side's heat loss is Gᵢ = Pᵢ / (Tᵢ − T_room).

Loss rises slightly faster than ΔT (convection and radiation), modelled as Pᵢ = Gᵢ·ΔTᵢ,test^(−n)·ΔT^(1+n). The new power splits in proportion to Gᵢ·ΔTᵢ,test^(−n) (just Gᵢ when n = 0), so every side reaches the same temperature. Wire length then follows from the new power and supply voltage: series R_total = V²/P, Lᵢ = R_total·(Pᵢ/P) / Ω/mᵢ; separate strings Lᵢ = V² / (Pᵢ·Ω/mᵢ).

Use full-on power for the test. If a thermostat or PID was cycling during the test, the real power was lower than calculated: the split between sides still holds, but the total watts in target mode will be overstated.

Neighbouring sides share heat at the corners, so the first correction is usually a little short. Rebuild, measure again, switch distribution to Length per side, enter the lengths you used and the new temperatures, and run it again. Raise gain k above 1 to correct harder in one step.

Wire estimate = predicted SS + wire load × R′. Pitch = area ÷ wire length for a serpentine. Both are estimates; check the silicone rating with your supplier.
